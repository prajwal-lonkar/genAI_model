# 🧠 Generative AI Projects with Node.js, OpenAI, LangChain & TypeScript

Welcome to my collection of AI-powered projects developed as part of a comprehensive Generative AI course. This repository showcases real-world implementations using cutting-edge tools like Node.js, TypeScript, the OpenAI API, and LangChain.

## 🚀 What This Repo Covers

This repository includes projects and code samples demonstrating:

- ✅ **How Generative AI works** – foundational concepts, use cases, and architecture
- ✅ **Node.js setup for AI development** – project scaffolding, package management, and API integration
- ✅ **OpenAI API Integration** – working with ChatGPT (text), DALL·E (image generation), and Whisper (speech recognition)
- ✅ **LangChain Framework** – building custom agents, chains, and tools to orchestrate AI behaviors
- ✅ **TypeScript for AI Engineers** – type-safe code for more scalable and maintainable applications
- ✅ **Real-World AI Projects** – chatbots, content generators, image transformers, voice transcription tools, and more
- ✅ **Deployment & Scaling** – best practices for running AI apps in production

## 🛠 Tech Stack

- **Node.js** – JavaScript runtime for backend logic
- **TypeScript** – Superset of JavaScript for type safety and better tooling
- **OpenAI API** – GPT (text), DALL·E (images), Whisper (audio)
- **LangChain** – For chaining LLMs with tools, memory, and APIs
- **dotenv** – Managing environment variables securely

## 📂 Code Structure

Each branch contains code related to respective model functionality. Below is the list of branches and short description of the code in the respective branch.

- **basics** – Setting OpenAI API key, installing and using the official OpenAI Node.Js SDK.
- **ai-chat-app** – Building a basic AI chat application. Context management for smart conversations.
- **tools** – Understanding and code for functions/tools in GenAI.
- **ai-image-generator** – Exploring OpenAI's DALL·E 1 model to bring your ideas to life.
- **text-to-speech-model** – Exploring OpenAI's tts-1 model to read aloud a provided text.
- **chromaDB_genAI** – Dive deep into ChromaDB, a powerful open-source vector database designed for AI, LLMs, and GenAI workflows.
- **langchain** – Step-by-step how to use LangChain for creating intelligent apps with tools, memory, agents, chains.

## 🧪 How to Run

1. Clone this repo:
   ```bash
   git clone https://github.com/prajwal-lonkar/genAI_model.git
2. Switch branches to view required code on respective branches.

3. Install dependencies:
   ```bash
   npm install

4. Add your OpenAI API key to a .env file:
   ```bash
   OPENAI_API_KEY=your-key-here

5. Run a project:
   Open terminal and run project in watch mode:
   ```bash
   tsc -w

  Open new terminal and run command :
  ```bash
  npm run dev
   ```
